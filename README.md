## What it does

`main.py` writes one roast of a daily gadget to `/output/entry.txt`. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line:

> My laptop fan screams like a jet engine every time I open a spreadsheet, as if the numbers personally offended it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
